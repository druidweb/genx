# About Genx

Genx is a Laravel package that provides custom generators and stubs for various file types. It is designed to work with the Druid Laravel starter kit and other Laravel projects, and provides Zen formatted generators/stubs that replace Laravel's default stubs, ensuring all generated PHP files follow Zen coding standards.
